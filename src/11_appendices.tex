% Include supporting material: full code listings, additional figures, data tables, user manuals, etc.

Supporting material that is too detailed for the main body but necessary for completeness. Typical content includes:

\begin{enumerate}
    \item Full source code listings
    \item Database schemas
    \item API documentation
    \item User manuals or installation guides
    \item Raw data tables or additional figures

\end{enumerate}
    
Each appendix should be a separate \section{} with a clear label (Appendix A, B, etc.) and referenced from the relevant chapter using \ref{app:a}.
